# Tracer website: Concept A, "The Trace"

One line of light draws the Tracer wordmark, then re-routes itself into each section's diagram: the RWA route,
the five Safes, the governance loop, Base blocks, the ecosystem hub and the roadmap. Tracy draws in at the FAQ.
A dot-grid field in depth gives light immersion without heavy 3D.

Structure and homepage plan: `../tracer-website/STRUCTURE.md` and `HOMEPAGE.md`.

## What's here

| Path | What |
|---|---|
| `site/` | The built site: 12 static pages. Vercel serves this folder as is (no build step). |
| `source/templates/trace/` | The template: `render.mjs` (pages), `app.js` (scroll story, labels, Tracy, UI), `scene/line.js` (the line), `scene/shapes.js` (the diagrams), `scene/field.js` (the dot grid), `style.css` |
| `source/sites/tracer/site.json` | All the words, the line's shapes and scroll keys per page (generated by `raw/make-site.py`) |
| `source/sites/tracer/raw/` | `make-site.py` (copy and keys), `contours.py` (logo → vectors), `tracy/tracy.py` (mascot assets) |

## Rebuild

The site is built with the Nalikes 3d-builder (`runtime/` and `tools/build-studio.mjs`), where these sources also live
(`templates/trace`, `sites/tracer`):

```bash
python3 sites/tracer/raw/make-site.py     # writes site.json
node tools/build-studio.mjs tracer        # -> dist/tracer/ (fonts need: pip install fonttools brotli)
```

Then copy `dist/tracer/` to `site/` here.
